## 📌 Overview

A console-based simulation of ATM operations. Users authenticate with a **User ID** and **PIN**, then perform transactions such as deposit, withdrawal, transfer, and view transaction history.

---

## ✨ Features

- 🔑 **Login Authentication** → User ID = **12345**, PIN = **1111**
- 💵 Deposit & Withdraw funds
- 🔄 Transfer to recipient accounts
- 📜 Transaction history tracking
- 🧩 Multi-class OOP design (`ATM`, `Account`, `Transaction`, `Bank`, `Main`)
